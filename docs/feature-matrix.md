## 8. 建议实施顺序

### P0 — 让“能用”变成“完整”

> 2026-11-12 已全部落地代码；2026-11-18 补上路由/单焦点树/控制中心/7 类设置。标 🟢 的项因远端电脑使用约束尚未做完整串流验收。

1. **手柄直通**：`gpd_connect` + 60Hz `gpd_update` + 零值/`gpd_disconnect`，轴/扳机/D-pad/震动。🟢
2. **画质档位下发**：`resolution/fps/quality/bitrate` 已接入 `ConnectOptions`，连接前读取设置。🟢
3. **自动重连**：3 次退避（2/4/8 秒）+ 5 秒断线看门狗 + 状态提示；与手动重连共用状态机。🟢
4. **快修设置项**：`gamepadStyle` 已写入 `InputRouter.style`；`keyboardDefault` 驱动键盘 Tab；`focusRingStyle` 驱动主题（真机验证）。✅
5. **触摸板补全**：双指点击右键、长按拖拽。🟢
6. **工具箱内容级焦点**：Tab 行 + 内容行；触摸板 5 键、快捷键 12 卡、状态页 2 键。🟢
7. **release-all 收口**：断线/切页/本地菜单统一释放键盘、鼠标按键 + 手柄零值。🟢

- 剪贴板文字同步（已做）

- 文件传输单文件 MVP（已做，待真机验收）；文件夹批量/拖放待做
- 多显示器切换
- 长按连发（已做）、键盘第二页
- 诊断统计开关 + 脱敏日志

## 10. 信息架构结论（2026-11-18）

对照官方 Android 4.46.0、TV 3.5.0、官方帮助页和第三方主控端后，确认三条规律：

1. **画质/帧率/分辨率不是只在全局设置里。** 官方移动端在串流内
   `操作 → 显示`，PC 在 `控制中心 → 画质`，TV 在 `功能菜单 → 画面设置`；
   全局设置只保存默认值。DuoRemote 目前只有 `设置 → 播放`，缺少串流内快捷入口，
   这是最明显的“不熟悉感”来源。
2. **外设与安全各有独立分组。** 官方把“手柄/鼠标/键盘/麦克风”合为外设，把
   “同步剪贴板/仅观看/锁屏/防窥”合为安全；两处在串流内和全局设置各有一份。
3. **文件传输/显示器/小窗既是连接前动作，也是串流内工具。** 官方不会只放一处。

因此下一步 UI 工作的 P0 是新增**串流内控制中心**（画面与显示/外设/安全/更多），
与全局设置共享状态，并在设备详情补“连接偏好”摘要；详细页面树、选项矩阵和术语对齐见
[feature-parity.md](feature-parity.md)。

**设计稿（2026-11-18）**：`docs/ui/index.html` 总览（含“页面流”入口表与单屏画廊）；控制中心 `duo-control-center.html`，
文件 `duo-files.html`，多屏 `duo-display.html`，按键映射 `duo-keymap.html`，工具 `duo-tools.html`，
账号 `duo-account.html`，设置 `duo-settings.html`。交互规格 `docs/ui/spec.md` 第 15 节。
