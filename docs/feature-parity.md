# DuoRemote 功能边界与信息架构对照

> 更新：2026-11-18
> 目的：以官方 UU 远程（Android 4.46.0 / TV 3.5.0 / 官方帮助页）和第三方主控端为参照，
> 记录“有哪些功能、每个选项放在哪个页面”，并给出 DuoRemote 的补齐建议。
> 原则：**高频选项在串流内可直接改，全局设置只做默认值**；同一选项允许在两处出现，但必须共享状态、
> 文案一致，并明确“是否需重连”。

## 0. 读法与置信度

- ✅ 官方帮助页/客户端文案明确
- ◐ 从 APK 字符串、资源或页面结构归纳，路径可能随版本变化
- ○ 第三方源码/文档明确
- — 未发现或该端不提供

页面缩写：

| 缩写 | 含义 |
| --- | --- |
| 登录 | 扫码/短信/设备 ID 协助 |
| 设备 | 首页/我的设备列表 |
| 详情 | 连接前的设备详情页 |
| 串流 | 已建立远控的画面页 |
| 操作 | 移动端串流内的“操作”面板（含顶部快捷栏） |
| 显示 | “操作”里的显示/画质分组 |
| 外设 | 手柄、鼠标、键盘、麦克风 |
| 安全 | 剪贴板、仅观看、锁屏、防窥 |
| 更多 | 网络、指南、小窗、文件传输、反馈 |
| 控制中心 | PC 端串流内的控制中心 |
| 设置 | 客户端全局设置 |

### 0.1 速查：高频选项在哪

| 选项 | 官方移动端 | 官方 PC | 官方 TV | DuoRemote v1 | 建议 |
| --- | --- | --- | --- | --- | --- |
| 分辨率 | 串流内 `操作 → 显示` | `控制中心 → 画质` | `功能菜单 → 画面设置` | 仅 `设置 → 播放` | 增加串流内“画面与显示” |
| 帧率 | 同上 | 同上 | 同上 | 仅设置 | 同上 |
| 画质/码率 | 同上（码率在高级选项） | 同上 | 同上 | 仅设置 | 同上 |
| 手柄/震动 | 串流内 `操作 → 外设` | `控制中心 → 外设` | `功能菜单 → 手柄设备` | 设置 + 本地菜单模式 | 增加串流内“外设” |
| 同步剪贴板 | `操作 → 安全` | `控制中心 → 安全` | — | `设置 → 键盘` | 增加“安全”分组 |
| 文件传输 | 设备详情 + `操作 → 更多` | 设备详情 + `控制中心 → 工具` | 功能菜单 | — | P1 |
| 观看模式 | 设备详情 + `操作 → 仅观看` | 设备详情 + `控制中心 → 工具` | — | — | P1 |
| 显示器/多屏 | `操作 → 显示` | `控制中心 → 显示屏` + 顶部页签 | `切换显示器` | — | P1/P2 |
| 超级屏/虚拟屏 | `显示` | `控制中心 → 显示屏/虚拟屏` + `+` | 自动创建虚拟屏 | — | P2 |

### 1.2 官方移动端逐页

#### 登录

- 扫码登录：生成二维码 → 手机确认 → 授权登录 ✅
- 短信登录：区号、手机号、6 位验证码、60 秒重发 ✅
- 远程协助：输入被控电脑 ID/验证码，等待对方同意 ✅
- 登录后 token 持久化；换账号需退出登录 ✅

#### 设备/首页

| 功能 | 位置 | 说明 |
| --- | --- | --- |
| 在线/离线分组 | 设备 | 在线设备优先，离线设备仍可见 |
| 最近连接 | 设备 | 最近使用排序/入口 ◐ |
| 添加设备 | 设备 | 引导在电脑安装并登录同账号；也支持设备 ID 协助 |
| 远程协助 | 设备 | 独立入口，输入 ID + 验证码 |
| 文件传输任务 | 设备 | 传输中/暂停/继续/中断提示；可从主页进入文件传输 ✅ |
| 设备详情 | 设备 → 详情 | 进入桌面、文件传输、观看模式、远程开机、重启/关机、重命名/删除 ✅ |
| 观看模式 | 详情 + 串流内“操作 → 仅观看” | 只查看不控制；可缩放/1:1/画笔批注；剪贴板、麦克风、手柄等输入禁用 ✅ |
| 远程开机 | 详情 | 需先在电脑端完成 WOL 配置 ✅ |

| --- | --- |

| 虚拟按键 | 悬浮球/控制栏、按键方案、隐藏按键、键位透明度、按键大小 ✅ |
| 断开/静音/全屏 | 串流内直接可达 ✅ |

#### 设置中心（移动端）

APK 字符串可见的顶层条目：播放、显示、声音、安全、快捷键、下载、关于、帮助与反馈 ◐。
其中“播放/显示”承担默认画质、分辨率、帧率、缩放等；“安全”承担剪贴板、指纹、自动解锁等。
**注意：这些默认值在串流内的“操作 → 显示/安全”里还有一份，且串流内修改优先。**

TV 端是手柄优先，和 Duo 最接近。功能菜单（`功能菜单`）字符串可见：

| 分组 | 选项 |
| --- | --- |
| 画面设置 | 跟随本机 (w×h)、跟随被控端 (w×h)、自动创建虚拟屏、帧率上限（30/60/…/不设限）、分辨率 ◐ |

  virtual_mouse、mouse_cursor、simulate_mouse、smart_mouse、virtual_plan、operation_guide、

这张表定义了官方产品边界：**画质/帧率/码率、真彩/HDR、多屏/虚拟屏/超级屏、手柄/鼠标/键盘、
剪贴板、文件传输、终端/端口映射、远程开机/关机/重启、隐私屏、观看模式、按键映射**。

### 1.6 生态/边缘功能（记录边界，不纳入 DuoRemote v1）

| 功能 | 位置 | 说明 |
| --- | --- | --- |
| 云电脑/云硬盘 | 首页/我的 | 排队、U 币计费、定时关机、后台挂机、云硬盘管理 ◐ |
| 游戏/应用快速启动 | 设备详情/首页 | 连接后同步已安装应用，点击远程启动；多开管理 ◐ |
| MuMu 模拟器直控 | 串流内 | 识别 MuMu 窗口，提供模拟器设置（分辨率/DPI/性能/渲染）与直控模式 ◐ |
| 无线副屏 | 设备/电脑端 | 把手机/平板变成电脑扩展屏；与文件传输互斥提示 ✅ |
| 远程协助 | 设备 | 伙伴 ID + 验证码、等待对方同意、屏幕共享、批注 ✅ |
| 终端 | PC 控制中心/工具 | 被控端 shell，多会话，离开页面继续运行 ◐ |
| 端口映射 | PC 控制中心/工具 | TCP/UDP 本地端口到远端端口 ◐ |
| 设备管理 | 设备详情 | 重命名、删除/解绑、壁纸、重启/关机 ✅ |
| 通知/插件 | 设置/后台 | 云电脑排队、文件传输完成、插件下载通知 ◐ |
| 账号/计费 | 我的 | 会员、时长、U 币、云硬盘；与远控主流程弱相关 ◐ |
| 更新/错误码 | 设置/关于 | 检查更新、错误码解释、反馈 ✅ |

这些能力说明官方产品不是单纯“串流器”，但 DuoRemote 的定位是 **Duo 上的远控主控端**，
云电脑、MuMu、无线副屏、计费等不进入 v1 边界；终端/端口映射属于可选 P2；
远程开机（WOL）暂不排期，因为当前没有可唤醒的测试硬件/被控端条件。

## 2. 第三方客户端功能与菜单

### 2.1 Antman2023/UURemote-ns（Switch）

| 能力 | 位置/做法 |
| --- | --- |
| 扫码/短信登录、设备列表 | 首页；A 连接，X 切换登录方式，Y 刷新 |

| Joy-Con/触屏当键鼠 | 左摇杆鼠标，ZR/ZL 左右键，右摇杆滚轮，A/B/X/Y=Enter/Esc/Space/Tab |

结论：最小可用链路，没有“设置页/串流菜单”概念。

### 2.3 Antman2023/UURemote-web（浏览器）

- 设备页有“连接偏好”摘要卡：`1080P 高清 / 60 FPS / H.264` + “更多设置”。
- “帧率与画面”弹窗：显示分辨率（720/1080/1440/2160）、视频帧率（30/60）、
  画面质量（流畅/均衡/高清/蓝光）、电脑声音；**保存后下次连接生效**。
- 串流工具栏：帧率与画面、键盘、手柄、断开连接、静音、全屏、连接详情、操作指南。
- 手柄只做浏览器检测，不转发输入。
- 操作指南分“连接电脑/键鼠操作/游戏手柄”三页。

### 3.1 从矩阵读出的三条规律

1. **画质/帧率/分辨率**：官方移动、PC、TV 都放在串流内，且全局设置只作为默认值。

2. **外设/安全**：官方把“手柄、鼠标、键盘、麦克风”合为外设，把“剪贴板、仅观看、
   锁屏、防窥”合为安全；串流内和全局设置各有一份。
3. **文件传输/显示器/小窗**：既是连接前设备详情动作，也是串流内工具；官方不会只放在一处。

## 4. DuoRemote 的目标信息架构

### 4.1 目标页面树

```
主页（双屏）
├─ 上屏：设备详情 + 连接偏好摘要
└─ 下屏：设备列表 + 账号/刷新/设置
串流
├─ 上屏：视频 + OSD（可点分辨率/FPS 芯片）
└─ 下屏：工具箱（触摸板/键盘/快捷键/状态）
   └─ ☰ / B：控制中心（新增）
      ├─ 画面与显示
      ├─ 外设
      ├─ 安全
      └─ 更多
设置（全局默认值）
├─ 画面 / 屏幕 / 外设 / 安全 / 网络 / 外观 / 关于
账号
```

### 4.2 新增：串流内“控制中心”

**入口**（三处，均打开同一面板）：

- 下屏工具栏 `☰`（现有按钮）
- 上屏 OSD 的分辨率/FPS 芯片（触摸或手柄选中）
- 本地菜单新增“画面与显示”项

**布局**（640×480dp 下屏，手柄优先）：

```
┌ 控制中心 ─────────────────────────────┐
│ 画面与显示 │ 外设 │ 安全 │ 更多        │  ← L1/R1 或 ←→ 切分组
├───────────────────────────────────────┤
│ 分辨率      跟随窗口 / 1080p / 720p   │
│ 帧率        30 / 60                   │
│ 画质        流畅 / 标准 / 高清         │
│ 码率上限    自动 / 10 / 20 / 50 Mbps   │
│ 缩放        适应 / 原始                │
│ 显示器      主屏 / 副屏（后续）        │
│                                       │
│ 当前：1920×1080 · 60 FPS · 高清        │
│ ⚠ 分辨率/帧率/画质修改后需重连          │
├───────────────────────────────────────┤
│ [应用并重连]              [关闭]       │
└───────────────────────────────────────┘
```

- 上下选择用 D-pad，左右改值，A 应用，B 关闭；不占用远端手柄输入（打开面板即 `gpd_disconnect`）。
- 画面类改动统一走“应用并重连”，避免用户以为立即生效。
- 与全局设置共享 `SettingsStore`，任何一处改动另一处即时可见。

**外设页**：

- 手柄直通、震动、风格（Standard/Retro）、死区 8/16/25%、左右 Y 反向
- 触摸板灵敏度、直接触摸开关
- 键盘默认（内置拼音/系统 IME）

**安全页**：

- 同步剪贴板（现有设置迁入）
- 仅观看（新增，输入全部拦截，剪贴板临时关闭）
- 断开后锁定远端（后续）
- 防窥/隐私屏（后续）

**更多页**：

- 网络状态（RTT/FPS/码率/丢包/通道）
- 诊断统计开关
- 操作指南（触摸板手势、手柄直通、快捷键）
- 反馈/关于

### 4.3 连接前：设备详情补“连接偏好”

在现有“准备远控”卡片下增加一行摘要（参考 UURemote-web）：

```
连接偏好   1080p · 60 FPS · 高清 · 自动码率      [调整]
```

- “调整”进入设置→画面；返回后摘要即时更新。
- 设备详情增加动作入口：`文件传输`（P1）、`观看模式`（P1）；`远程开机`暂不做
  （没有可唤醒的测试硬件/被控端条件）。
- 不可用能力置灰并标注“需电脑端支持/后续版本”，不要做成可点但无反应。

### 4.4 全局设置重组

| 现分类 | 建议分类 | 迁移内容 |
| --- | --- | --- |
| 播放 | **画面** | 分辨率、帧率、画质、码率、缩放（后续 HDR/编码） |
| 屏幕 | **屏幕** | 双/单屏、单屏宿主、旋转（后续） |
| 手柄 + 触摸板 + 键盘 | **外设** | 手柄直通/震动/风格/死区/反向、触摸板灵敏度/直接触摸、键盘默认/候选数 |
| （无） | **安全** | 同步剪贴板、仅观看、断开锁屏、防窥 |
| 网络 | **网络** | 自动重连、诊断统计、中继（后续） |
| 外观 | **外观** | 主题、焦点环、触感/按键音 |
| 关于 | **关于** | 版本、GPL、非官方声明、更新检查（后续） |

设置项保留“立即生效/重连生效”的小字，和官方一致。

### 4.5 术语对齐

| 官方用语 | 我们当前 | 建议 |
| --- | --- | --- |
| 操作 | 工具箱/本地菜单 | 保留“本地菜单”，新增“控制中心”作为面板名 |
| 显示 | 播放 | **画面与显示**（设置分类用“画面”） |

### 4.6 建议实施顺序

**P0（熟悉感，改动小）**

1. 控制中心壳 + 画面与显示页（分辨率/帧率/画质/码率/缩放 + 应用并重连）。
2. 外设页（手柄/触摸板/键盘）与安全页（同步剪贴板）。
3. 设备详情“连接偏好”摘要。
4. 设置分类重组与术语对齐。
5. OSD/工具栏显示当前 `分辨率 · FPS`，点击进控制中心。

**P1（日常完整度）**

6. 仅观看模式。
7. 文件传输（设备详情 + 控制中心→更多）。
8. 显示器切换（顶部/下屏页签）。
9. 操作指南、网络状态整合进“更多”。
10. 小窗模式（Android PiP）。

**P2（对标官方增强）**

11. 超级屏/虚拟屏/多屏页签。
12. 实体手柄→键鼠模拟（内置模板）；触屏虚拟按键/轮盘不做。
13. 重启/关机、终端、端口映射；远程开机（WOL）暂不做（无测试条件）。
14. H.265/4K/HDR/真彩、更新检查、多语言。
