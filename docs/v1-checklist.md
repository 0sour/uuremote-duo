# DuoRemote v1 完成清单

> 更新：2026-11-18
> 目标：Duo 横屏、手柄优先、双屏/单屏、可日常远控。以下“完成”指代码已落地并通过构建/单测；
> v0.2 串流、控制中心、仅观看、缩放、单屏与手柄说明已在 RP Duo 真机验收（见 §8）。
> 官方/第三方功能与选项位置对照见 [feature-parity.md](feature-parity.md)。

## 1. 账号与设备

- [x] 官方 TV APK 本地提取签名 key（指纹校验、加密保存、不落日志）
- [x] 扫码登录 / 短信登录 / token 持久化
- [x] 设备列表、在线状态、手动刷新
- [x] 设备详情：系统、分辨率（有则显示）、上次连接（Unix 秒/毫秒格式化）
- [x] 账号页：上屏只读摘要（真实昵称/在线数/版本）+ 下屏操作；刷新、二次确认退出登录、返回
- [x] 串流内控制中心：画面与显示 / 外设 / 安全 / 更多；工具条 `1080p·60` 与本地菜单入口

## 2. 串流

- [x] 加入房间 → Engine.IO → control → SOAC → WebRTC H.264
- [x] 1080p/720p、30/60 FPS、画质档位、码率上限下发
- [x] 音频播放/静音
- [x] 首帧提示、实时 FPS/码率/RTT/丢包
- [x] 手动重连 + 2/4/8 秒三次自动重连 + 5 秒断线看门狗
- [x] 后台保留会话，onStop 静音并释放远端输入
- [x] 下屏拔插：会话不重建，只切换 Presentation/单屏布局
- [x] 画面缩放：适应 / 铺满 / 原始（RemoteVideo `SCALE_ASPECT_*`）
- [x] 仅观看：释放并拦截键鼠/触屏/手柄/文字，暂停剪贴板；本地 UI 仍可操作（客户端门控）
- [x] 后台小窗：单屏串流按 Home 进入 PiP，只保留视频；Duo 真机验证

## 6. v1 明确不做

- 拖放 / 剪贴板图片与文件（文件夹上下传含子目录、多文件顺序传输已落地）
- 多显示器切换、多屏页签、超级屏 / 虚拟屏
- H.265 / AV1、4K / 144Hz、真彩 / HDR
- 远程开机（WOL）：暂不做（没有可唤醒的测试硬件/被控端条件）
- 重启 / 关机 / 定时关机、终端、端口映射
- 被控端强制的观看模式（本版仅观看为本机客户端门控）
- 按键映射 / 宏 / 轮盘 / 虚拟摇杆
- 麦克风、多语言、双屏亮度联动
- 应用更新检查（公开仓库地址未定）
- 自定义按键映射、手柄当键鼠

- 直接触摸移动远端光标后，同步写回 `StreamingUiState.cursorX/Y`；此前触摸板点击会先把
