# DuoRemote 交互与状态规格

> 版本：v0.1（2026-11-11）
> 本文定义**行为、状态、焦点、异常与验收**；视觉数值见 [tokens.md](tokens.md)，协议与架构见 [research.md](../research.md)。
> 适用：Retroid Pocket Duo 双屏、单屏横屏（上屏 Activity / 下屏 Presentation）。**不做竖屏。**

---

## 1. 全局规则

1. **横屏唯一**：Activity 锁定横屏；单屏也必须是横屏。不提供竖屏布局、不跟随传感器旋转。
2. **双屏分工**：上屏展示信息/视频，下屏承担列表、设置、工具箱。上屏默认不接收手柄焦点。
3. **单一焦点树**：同一时刻只有一个宿主拥有手柄焦点；双屏时默认是下屏 Presentation，单屏时是当前宿主。
4. **输入归属显式**：手柄、键盘、鼠标、触摸各自有明确消费者；不允许两个窗口同时处理同一按键。
5. **本地语义不污染远端**：UI 提示按 Duo 实体丝印（B 确认 / A 返回）；入口归一化为 canonical Xbox 后再分发，远端始终收到标准 Xbox 映射。
6. **不占用额外手柄组合键**：本地菜单只通过系统 Return/Back 或触摸按钮打开，不用 L1+R1+START 等组合。
7. **模态只用 Compose overlay**：Presentation 内不使用 `Dialog`/`AlertDialog`/`ModalBottomSheet`（window type 不匹配）。
8. **敏感信息不落日志/界面**：token、二维码内容、SDP、IP、账号手机号、签名 key 均不显示、不记录。
9. **所有异步操作可取消**：登录、刷新、连接、首帧等待、重连均需可取消，并在取消时释放资源。
10. **默认值可恢复**：设置页提供“恢复默认”，但不清除登录态与签名材料。

## 2. 导航与宿主

### 2.1 双屏导航

```text
Top Activity                         Bottom Presentation
─────────────                        ───────────────────
KeySetup / Login(QR/SMS)     ←→      Login steps / SMS form
DeviceDetail                 ←→      DeviceList
Connecting                   ←→      Connecting status + Cancel
Streaming video              ←→      Toolkit: Touchpad / Keyboard / Shortcuts / Stats
Settings preview             ←→      Settings categories + options
```

- 启动时先决定宿主：有下屏且模式允许 → 显示 `DuoPresentation`；否则进入单屏。
- 双屏主页：下屏列表拥有焦点；上屏详情只读。B 连接、A 返回、Y 刷新、X 账号、START 说明；设置走头部图标。
- 双屏串流：上屏只显示视频/连接状态；下屏工具箱。默认手柄直通，本地菜单/本地操作才接管手柄。
- 双屏设置：下屏分类+选项；上屏显示当前配置摘要/焦点预览，随设置即时更新。
- 登录：上屏二维码/说明，下屏步骤与“短信登录”入口；登录成功后两侧同时切主页。

### 2.2 单屏导航

单屏只有一棵 UI 树，按宿主不同放在上屏 Activity 或下屏 Presentation：

```text
KeySetup / Login → Home(master-detail) → Streaming(video + drawer)
                        ↘ Settings
```

- 主页：左列表（约 56%）+ 右详情（约 44%）；640 宽度下详情只保留名称/状态/系统/连接按钮。
- 串流：视频铺满，底部工具箱抽屉默认 42%；键盘页/IME 自动升到 58%，可拖到 68%；收起后保留悬浮“工具箱”按钮。
- 设置/登录：单屏内完成，不依赖另一块屏。
- 单屏跑下屏时，上屏 Activity 只做黑色/待机宿主，不显示内容、不抢焦点。

### 2.3 返回栈

| 场景 | 返回行为 |
| --- | --- |
| 系统 IME 可见 | 先收系统 IME |
| 内置拼音浮层 | 先收浮层（保留键盘页） |
| 键盘页（内联） | 不消费返回；IME/浮层未开时返回打开本地菜单 |
| 工具箱抽屉 | 不消费返回；用把手/按钮收起 |
| 本地菜单 | 关闭菜单并恢复之前的输入归属 |
| 设置子页 | 回设置分类；再按回主页 |
| 主页根 | 弹“退出应用？”overlay；B 确认、A 取消 |
| 串流中 | 打开本地菜单（不直接断开） |

- 返回事件在 Activity 与 Presentation 各接一次，统一进入 `Session.handleBackKey()`，250ms 去抖。
- 返回优先级：`SystemIme → BuiltinOverlay → LocalMenu → PageBack`。抽屉不是模态，不消费 Back；
  串流中一次返回即可打开本地菜单。
- 断开连接只能从本地菜单/设置中的“断开连接”触发，返回键不直接断流。

## 3. 启动、签名材料与登录

### 3.1 首次启动 / 签名材料

没有可用签名材料时，先进入 KeySetup，不显示登录页。

| 状态 | 界面 | 操作 |
| --- | --- | --- |
| `NoKey` | 说明“需要官方 UU TV 3.5.0 APK 提取签名材料”；选择 APK / 退出 | 选择文件 |
| `Extracting` | 进度 + “只在本机解析，不上传” | 可取消 |
| `KeyReady` | 显示指纹前 8 位 + “材料已加密保存” | 继续登录 / 重新导入 |
| `KeyInvalid` | 原因（不是目标 APK/解析失败/指纹不符）+ 重试 | 重新选择 |
| `KeyError` | 存储失败/权限错误 + 重试 | 返回 |

- 只读取 APK 内的 `classes*.dex`，不安装、不执行、不上传；提取完成删除临时副本。
- 指纹校验失败必须拒绝保存；错误文案不显示 key 内容。
- 设置 → 关于/安全中可查看“签名材料状态”和重新导入；清除材料需二次确认。

### 3.2 扫码登录

| 状态 | 上屏（双屏）/单屏 | 下屏/单屏操作 |
| --- | --- | --- |
| `QrLoading` | 二维码骨架 + “正在获取二维码…” | 取消/短信登录 |
| `QrWaiting` | 二维码 + 有效期 | Y 刷新、X 短信登录、A 返回 |
| `QrScanned` | 二维码变暗 + “已扫码，请在手机上确认” | 等待 |
| `QrExpired` | 过期遮罩 + “二维码已过期” | Y/按钮刷新 |
| `QrSuccess` | “登录成功，正在进入…” | 自动进主页 |
| `QrError` | 原因 + 重试 | Y 重试 / X 短信 |

- 倒计时最后 30s 显示警告色；过期自动停止轮询。
- 二维码内容不写日志、不落盘；只保留内存 Bitmap。
- 登录成功保存 token（加密）并拉取设备列表；失败保留在登录页。

### 3.3 短信登录

| 状态 | 行为 |
| --- | --- |
| 输入手机号 | 区号默认 +86；手机号格式本地校验；系统数字键盘 |
| 发送验证码 | 按钮进入 60s 倒计时；失败显示原因并可重发 |
| 输入验证码 | 6 位数字；自动提交或点“登录” |
| 登录中 | 按钮 loading，禁止重复提交 |
| 登录失败 | 验证码错误/过期/频率限制，保留手机号，清空验证码 |
| 返回 | 回扫码登录；不丢失已输入手机号（仅内存） |

- 手机号/验证码只用于本次请求，不写日志、不落盘。
- 系统输入法在此页面是正常路径；流式键盘的内置拼音不用于手机号输入。

### 3.4 登录失效

- API 返回未登录/ token 失效：停止轮询/连接，清 token，回登录页并提示“登录已过期，请重新登录”。
- 串流中失效：先断开会话并释放输入，再回登录页；不要停留在黑屏。

## 4. 设备列表与详情

### 4.1 状态

| 状态 | 下屏/单屏列表 | 上屏/单屏详情 |
| --- | --- | --- |
| `Loading` | 4 张骨架卡 + “正在读取设备…” | 骨架/说明 |
| `Ready` | 设备卡列表；在线/离线状态点 | 选中设备详情 |
| `Empty` | 空态图标 + “还没有可远控的电脑” + 刷新 | 说明卡：在电脑安装/登录 UU 远程 |
| `OfflineAll` | 列表仍显示，全部灰化 + 顶部提示 | 离线原因 + 刷新 |
| `Error` | 错误图标 + 原因 + 重试 | 同步错误说明 |
| `Refreshing` | 顶部细进度条；列表保持可读 | 不闪烁 |

- 列表排序：在线优先，其次最近连接；离线设备保留但降低不透明度。
- 每屏 4 张卡（下屏 76dp）或 4–5 张（单屏 72dp）；焦点卡外环 + 左侧强调条。
- Y/刷新按钮触发；前台恢复时自动刷新一次；不在串流中轮询。
- 刷新失败保留旧列表，顶部显示“刷新失败，显示上次结果”。

### 4.2 连接前检查

- 设备离线：B/连接按钮禁用，提示“电脑离线。请在电脑上打开 UU 远程后刷新。”
- 已在其他会话中：提示“该电脑正在被其他设备控制”，提供重试/取消（是否支持抢占由服务端决定）。
- 不支持的系统/协议：提示原因，不进入连接。

### 4.3 连接阶段

连接开始后：

- 上屏/单屏视频区只显示阶段进度；取消按钮在下屏/抽屉，上屏不放控件。
- 阶段：`JoiningRoom → Signaling → Negotiating → WaitingFirstFrame`。
- 首帧到达前不显示黑屏；显示最近一帧/占位背景 + 阶段。
- 任一步超时/失败 → 错误页，提供“重试 / 返回设备列表 / 查看诊断”。
- 取消必须释放 socket、PeerConnection、数据通道、输入按住状态。

## 5. 串流会话状态

### 5.1 状态机

```text
Idle
 └─ JoiningRoom ─→ Signaling ─→ Negotiating ─→ WaitingFirstFrame ─→ Streaming
        │              │             │                │
        └──────────────┴─────────────┴────────────────┴─→ Failed / Cancelled

Streaming ─→ Reconnecting ─→ Streaming
     └─────→ Closed
```

| 状态 | 超时 | UI | 允许操作 |
| --- | --- | --- | --- |
| `JoiningRoom` | 15s | “正在加入房间…” | 取消 |
| `Signaling` | 15s | “正在建立安全连接…” | 取消 |
| `Negotiating` | 15s | “正在协商画面…” | 取消 |
| `WaitingFirstFrame` | 30s | “等待电脑画面…” + 已连接提示 | 取消 |
| `Streaming` | — | 视频 + 工具箱 | 全部 |
| `Reconnecting` | 3 次/12s | 视频冻结/占位 + “正在重连…” | 取消/返回 |
| `Failed` | — | 原因 + 重试/返回/诊断 | 重试/返回 |
| `Closed` | — | 回设备列表/主页 | — |

### 5.2 串流中

- 上屏只显示视频；默认无 OSD；可在设置打开左上角小统计。
- 下屏工具箱默认触摸板；Tab：触摸板/键盘/快捷键/状态。
- 音频默认播放电脑声音；麦克风默认关闭且不采集。
- 保持屏幕常亮；隐藏系统栏（沉浸式，边缘滑动可临时呼出）。
- 统计：FPS、码率、RTT、丢包、分辨率、编码/解码、P2P/TURN、会话时长。

### 5.3 重连

- WebRTC `FAILED/DISCONNECTED`：先尝试 ICE restart/等待 12s，最多 3 次。
- 重连期间视频冻结最后一帧并显示小横幅；不弹全屏遮罩，避免打断。
- 3 次失败：显示“连接已断开”+ 重试/返回；释放输入并发送零值/`gpd_disconnect`。
- 服务端 `released`/`left`：立即结束会话，提示原因，回设备列表。
- 主动断开：本地菜单/设置触发，先释放输入，再关闭 PeerConnection，回列表。

### 5.4 前后台

- 切后台/锁屏：保持会话 60s，暂停视频渲染并静音；回前台恢复。超过 60s 或系统回收则断开并回列表。
- 回前台时若会话已失效：提示“会话已结束”，不自动重连到未知状态。
- 音频焦点丢失：暂停远端声音，恢复后继续。

## 6. 输入所有权与焦点

### 6.1 手柄三态

| 状态 | 触发 | 手柄 | 远端 `gpd` |
| --- | --- | --- | --- |
| `HOME_LOCAL` | 登录/主页/设置 | 本地焦点导航 | 不发送 |
| `STREAM_PASSTHROUGH` | 进入串流默认 | 直通远端 Xbox | `gpd_connect` + 60Hz `gpd_update` |
| `STREAM_LOCAL` | 本地菜单/工具箱“本地操作” | 本地焦点导航 | 暂停：零值 + `gpd_disconnect` |

补充：

- 本地菜单是“临时本地态”：从 `STREAM_PASSTHROUGH` 打开时暂停直通，关闭后恢复直通；若用户已显式切到“本地操作”，则关闭菜单后仍保持本地。
- 切换顺序固定：**先发零值 `gpd_update` → 再 `gpd_disconnect` → 才把事件交给本地焦点树**；切回时 `gpd_connect` 后再发状态。
- 离开串流/断开：零值 → `gpd_disconnect` → release all 键盘/鼠标按住的键。
- 本地导航吞掉 `repeatCount>0` 的方向/返回/肩键；直通状态按 60Hz 发当前状态，不受本地 repeat 影响。
- 不要全局拦截 `dispatchGenericMotionEvent`；`AXIS_HAT_X/Y` 必须放行，只有本地模式且确有摇杆消费者时才消费 `AXIS_X/Y`。
- 输入入口做 `GamepadStyle.normalizeFaceKey`；UI 提示永远写实体丝印 B/A/Y/X。

### 6.2 焦点模型

| 页面 | 初始焦点 | 焦点范围 | 说明 |
| --- | --- | --- | --- |
| 双屏主页 | 下屏第一张在线设备 | 设备列表 | 上屏详情不参与焦点 |
| 单屏主页 | 左列表第一张在线设备 | 列表 | 右侧连接按钮触摸可用；B 直接连接 |
| 签名导入 | “选择官方 TV APK” | 按钮组 | A 选择；B 退出 |
| 登录 · 扫码 | “刷新二维码” | 刷新 / 短信入口 | A 确认、Y 刷新、X 切短信、B 返回 |
| 登录 · 短信 | “手机号”输入框 | 手机号 → 验证码 → 获取验证码 → 登录 → 返回扫码 | A 确认/进入输入；B 先退出输入，再返回扫码 |
| 设置 | 第一个分类/选项 | 左分类 ↔ 右选项 | L1/R1 切分类 |
| 工具箱 | 当前 Tab | Tab + 内容控件 | 仅本地操作模式显示焦点环 |
| 本地菜单 | “继续远控” | 菜单项 | 关闭后焦点回到来源 |
| IME 浮层 | 候选条/键盘 | 候选 + 键盘 | 见 §7 |

- **页面首次进入就必须绘制焦点环**，不能等第一次按键后才出现；否则用户会认为手柄未适配。
- 焦点环外扩 4dp，绘制在 clip 之前；列表滚动时保证焦点项完整可见。父容器需留出 ≥4dp 空间，避免焦点环被裁切。
- 输入框获得选中时同时显示焦点环和高亮边框；按 A 进入输入并唤起系统输入法，按 B 退出输入状态。
- 部分手柄会同时上报 `BUTTON_A` 和合成的 `DPAD_CENTER`；确认以 `BUTTON_A` 为准，必须吞掉合成点击，避免重复触发或误点内部焦点控件。
- 焦点不跨宿主：双屏时上屏不持焦点；单屏切宿主时重新建立初始焦点。
- 关闭 overlay 后恢复之前的焦点；页面返回后恢复列表滚动位置。
- 禁用项不进入焦点；加载中的按钮不接收确认。

### 6.3 触摸 / 手柄 / 键鼠并用

- 下屏触摸板发鼠标事件，不抢手柄；手柄直通时仍可触摸工具箱。
- 上屏“直接触摸”默认关闭；打开后触摸视频映射为绝对鼠标坐标，黑边不发送。
- 本地模式下触摸与手柄都可操作同一焦点树；触摸不强制显示焦点环（最后一次输入类型决定）。
- 键盘/鼠标在切页、断开、进入本地菜单时释放所有按住的键。

### 6.4 本地菜单

- 打开方式：系统 Return/Back、下屏“菜单”按钮、单屏悬浮菜单按钮。**不用手柄组合键。**
- 菜单项：继续远控、手柄模式（直通/本地）、设置、断开连接。
- 打开时显示“远端手柄已暂停”状态；关闭后按 §6.1 恢复。
- 断开连接需二次确认；确认后释放输入并关闭会话。

## 7. 键盘与中文输入

### 7.1 状态机

```text
KeyboardClosed
  ├─ 点击输入行 → OverlayZh / OverlayEn（保留当前语言）
  ├─ 键盘 Tab → InlineZh / InlineEn
  └─ 系统输入法按钮 → SystemIme

InlineZh ⇄ InlineEn        （键盘“中/英”键）
OverlayZh ⇄ OverlayEn      （浮层“中/英”键）
OverlayZh/En → SystemIme   （浮层“系统输入法”）
SystemIme → OverlayZh/En   （收起系统 IME，回到内置）
```

| 状态 | 候选条 | 字母键 | 说明 |
| --- | --- | --- | --- |
| `InlineZh` | 显示（有组合时） | 进本地拼音组合 | 键盘页内联 |
| `InlineEn` | 隐藏 | 直接发 VK | 英文模式 |
| `OverlayZh` | 显示 | 进本地拼音组合 | 全屏候选浮层 |
| `OverlayEn` | 隐藏 | 直接发 VK | 全屏英文 |
| `SystemIme` | 系统绘制 | 系统处理 | 内置键盘隐藏 |

- “中/英”键在键盘底部，高亮表示中文；切换只影响内置输入，不影响系统 IME。
- 输入行右侧展开图标打开浮层；没有独立“拼音”按钮。
- 系统 IME 可见时隐藏内置键盘；系统 IME 收起后回到进入前的内置状态。

### 7.2 内置拼音

- 本地词典 + 拼音切分；字母输入实时出候选，最多 7 个，可翻页。
- 空格提交首选；数字键 1–9 选候选；方向键左右移动候选（本地模式）；点击候选直接提交。
- 组合最长 32 个字母；超过后不再接受字母，提示音/触感可关。
- 退格：有组合先删拼音；无组合发 VK 8。
- 回车：有组合先提交首选/原始组合，不额外发 Enter；无组合发 VK 13。
- 中文标点：`，。！？：；` 走 `text_input`；英文标点走 VK。
- 英文模式：字母/数字/符号走 VK press/release；Shift/Caps 本地粘滞，不改变远端锁定状态，除非用户显式按 Caps。
- 修饰键：Ctrl/Alt/Shift/Win 粘滞或锁定；切页/断开时全部释放。
- 长按 Backspace/方向键 350ms 后每 50ms 连发；视觉保持按下态。
- 提交失败：重试一次；仍失败则保留输入内容并提示“发送失败，请重试”，不静默丢失。

### 7.3 系统输入法

- 点击“系统输入法” → 聚焦隐藏/可见 `EditText`/`BasicTextField` → `InputMethodManager.showSoftInput`。
- 系统 IME 的候选/键盘由系统绘制；应用只转发 `commitText`。
- `setComposingText` 只本地显示；`commitText` → `text_input`；`sendKeyEvent(Enter/Backspace)` → VK 13/8。
- `deleteSurroundingText(n)` → 发 n 次 VK 8（或按协议支持的文本删除）。
- 系统 IME 收起/失焦：恢复内置键盘与之前的语言状态。
- 下屏 Presentation 的系统 IME 需真机验证；若副屏不显示，禁用/隐藏系统按钮并提示“当前屏幕不支持系统输入法，请使用内置拼音”。
- 系统 IME 出现时，工具箱内容区按 inset 压缩；不要用 `WindowInsets.isImeVisible` 作为唯一判断，维护 `ImeState.shown`。

### 7.4 远端协议

- 中文/整段文本：`{"action":"text_input","content":"..."}`（CONTROL 通道）。
- 失败回退：`SendToRom{RomMsg_Text}`（TEXT 通道）→ 剪贴板 RPC + Ctrl+V（v1 可选，默认关闭）。
- 英文/控制键：`kbd_press`/`kbd_release` + Windows VK。
- 手柄：`gpd_connect` / `gpd_update` / `gpd_disconnect`；中文输入不产生手柄事件。
- 所有输入在断线/切页/本地菜单暂停时 release all。

## 8. 双屏宿主生命周期

- **创建**：Activity 启动 → 枚举 displays → 有下屏且模式允许 → 创建/显示 `DuoPresentation`；共享 Activity-scoped `SessionViewModel`。
- **Presentation 内容**：设备列表/登录/设置/工具箱；ComposeView；Lifecycle/ViewModelStore/SavedState/BackDispatcher owner 与 bili-duo 模式一致。
- **焦点**：Presentation 显示时拥有焦点；Activity 不处理手柄导航。系统 Back 由当前焦点宿主接收，统一路由。
- **显示移除**：`onDisplayRemoved` → dismiss Presentation；若正在串流，顶部/单屏 failover，保持会话并提示“下屏已断开，已切换单屏”；输入归属重建。
- **显示新增**：主页时自动显示下屏；串流中不自动切换，提示“检测到下屏，下次连接生效”（v1 避免焦点跳动）。
- **Activity 重建**：锁定横屏 + `configChanges`；ViewModel 保留会话；Presentation 重新 attach；不重复 join/登录。
- **锁屏/后台**：见 §5.4；回前台重新绑定 Surface/焦点。
- **Presentation 内禁止**：`Dialog`、`AlertDialog`、`ModalBottomSheet`、依赖 window 的 Popup；全部用 Compose overlay。
- **IME**：下屏自建 `ImeState`；系统 IME 可能改变下屏可用高度，工具箱需 resize/滚动。

## 9. 单屏宿主

### 9.1 宿主选择

设置项：`屏幕模式 = 自动 / 双屏 / 单屏`；`单屏宿主 = 自动 / 上屏 / 下屏`。

| 模式 | 有下屏 | 无下屏 |
| --- | --- | --- |
| 自动 | 双屏 | 单屏上屏 |
| 双屏 | 双屏 | 单屏上屏 + 提示“未检测到下屏” |
| 单屏 + 自动 | 单屏上屏（优先） | 单屏上屏 |
| 单屏 + 上屏 | 单屏上屏 | 单屏上屏 |
| 单屏 + 下屏 | 单屏下屏（上屏黑色宿主） | 回退单屏上屏 + 提示 |

- 单屏下屏：整个 UI 在 Presentation；Activity 只保留黑色/待机背景，不显示内容、不抢焦点。
- 单屏上屏：普通 Activity，系统 Back/IME 正常。
- 启动后不在会话中切换宿主；设置修改在下一次进入主页/连接时生效。

### 9.2 窗口与系统栏

- 锁定横屏；`WindowInsets` 处理刘海/圆角/手势区；视频页隐藏系统栏，边缘滑动临时呼出。
- 单屏下屏的 Presentation 需可聚焦、可接收 IME；背景黑色，避免漏光。
- 屏幕常亮仅在串流中；主页/设置遵循系统休眠。

### 9.3 返回与 IME

- 上屏 Activity：正常 `OnBackPressedDispatcher`；优先级见 §2.3。
- 下屏 Presentation：`dispatchKeyEvent` 接 `KEYCODE_BACK/ESCAPE` + API 33 `OnBackInvokedCallback`，250ms 去抖；不能依赖 Activity 一定收到。
- 下屏系统 IME：见 §7.3；内置拼音始终可用。

## 12. 无障碍、性能与安全

### 12.1 无障碍

- 正文对比度 ≥ 4.5:1；大字号 ≥ 3:1；焦点环在亮/暗主题都可见。
- 可点击区域 ≥ 44dp（优先 48dp）；键盘键帽 ≥ 38dp 高。
- 图标按钮必须有 `contentDescription`；状态不能只靠颜色，配文字/图标。
- 支持系统字体缩放 1.0–1.3；超过 1.3 用滚动，不裁切关键操作。
- 尊重“减弱动态效果”：抽屉/浮层动画可关闭或缩短。

### 12.2 性能预算

- 局域网首帧：加入房间后 < 5s（目标 3s）。
- 输入延迟：LAN < 30ms；同屏操作无可感知卡顿。
- 视频：1080p60 稳定；掉帧时优先降码率，不降输入响应。
- 内存：串流峰值 < 300MB；无持续增长。
- 发热：30 分钟串流不降频到不可用；提供 720p30 档。

### 12.3 安全与隐私

- 签名 key、token 使用 EncryptedSharedPreferences/Keystore 加密；不写日志、不导出。
- 首次运行 APK 只读解析、不安装、不上传；临时文件用后删除。
- 二维码内容、SDP、IP、手机号不显示在诊断/日志；诊断默认关闭。
- 禁止明文 HTTP；只允许 HTTPS/WSS；证书校验默认开启。
- 剪贴板同步默认关闭；开启时明确提示“会读取/写入剪贴板”。
- 可选 `FLAG_SECURE`（设置项，默认关）防止截图/录屏泄露远程画面。
- 第三方客户端/账号风险在首次启动与关于页说明；不绕过付费/风控。

## 15. 2026-11-18 控制中心与功能面扩展

### 15.1 控制中心入口

三个入口打开同一面板：

1. 下屏工具栏 `☰`（串流内）；
2. 下屏工具条的 `1080p·60` chip；
3. 本地菜单 `画面与显示 / 外设 / 安全 / 更多`。

打开面板时：`releaseAllInput()` + 零值 `gpd_update` + `gpd_disconnect`；关闭后恢复
直通并重新 `gpd_connect`。面板内不向远端发送手柄输入。

### 15.2 画面类“待应用”状态机

- 用户在面板内改分辨率/帧率/画质/码率/缩放时，只改本地 pending 值，不立即写 Store。
- 顶部出现“有 N 项待应用”；底部主按钮变为 `应用并重连 · N 项`。
- `应用`：写 Store → 关闭面板 → 调用 `connectSession(device, options)` 重连；
  重连期间显示“正在重新协商串流…”。
- `取消`：丢弃 pending，回到当前 Store 值。
- 输入类（外设/安全）立即写 Store 并调用 `SessionController.configure`，不重连。
- 若当前无会话，面板仍可从主页打开；画面类只写 Store，下次连接生效。

### 15.3 外设

| 项 | 生效方式 |
| --- | --- |
| 手柄直通 | 立即；关闭时 release-all + `gpd_disconnect` |
| 震动 / 风格 / 死区 / Y 反向 | 立即写 Store + `configure` |
| 触摸板灵敏度 / 直接触摸 | 立即 |
| 键盘默认 / 候选数 | 立即；下次打开键盘 Tab 生效 |

### 15.4 安全 / 仅观看

- 同步剪贴板：立即写 Store + `configure`；关闭时移除监听。
- 仅观看：本地持久化开关，开启时：
  - `setInputSuppressed(true)`，调用 `releaseAllInput()` 和 `releaseGamepad()`；
  - 触摸板/键盘/快捷键/手柄输入全部拦截；
  - 剪贴板同步临时关闭（不改 Store，退出后恢复）；
  - 上屏显示 `仅观看 · 输入已锁定` chip；下屏工具条显示“仅观看中”。
- 仅观看不影响远控权限；断线重连默认回到操控模式。
- 断开锁屏/防窥/指纹解锁在 v1 只做占位，置灰并标注“后续”。

### 15.5 设置分类

`画面 / 屏幕 / 外设 / 安全 / 网络 / 外观 / 关于`。

- 画面类与串流内控制中心共享同一 Store；控制中心是快捷入口，设置是完整入口。
- 术语：`帧率上限`、`跟随本机`、`跟随被控端`、`同步剪贴板`、`仅观看`、`重连后生效`。

### 15.6 文件传输

- 入口：主页下屏动作条“文件”、控制中心 → 更多、本地菜单“页面 → 文件传输”。
- 上屏只读：传输总览、进度、本机剩余空间；不放按钮。
- 下屏唯一操作台：“浏览 / 队列 / 存储”三个页签；选择、下载、上传、暂停、取消、打开目录、保存路径都在下屏。
- 同一被控端同时只跑一个传输任务；普通传输支持断点续传；拖拽不支持。
- 传输期间不要退出控制桌面；移动端从主页进入文件传输后退出可能导致连接中断。

### 15.7 多屏 / 超级屏 / 虚拟屏

- 屏幕列表/页签是显示器切换入口（上屏只读预览，下屏操作）；`+` 创建虚拟屏；页签可拖出独立窗口。
- 超级屏：控制中心/画面与显示 → 物理显示屏 → 切换使用超级屏；进入前确认“物理屏关闭”。
- 虚拟屏：最多 3 块，物理+虚拟合计最多 5；删除当前虚拟屏会切到下一屏。
- 超级屏与虚拟屏互斥；远程协助不支持超级屏/虚拟屏创建。

### 15.8 按键映射

- 入口：控制中心/操作 → 按键映射。
- 方案列表：官方方案、我的方案、新建；启用开关即时生效。
- 编辑：单个按键类型（控制键/数字键/功能键/鼠标与轮盘/宏）、大小、不透明度、
  触发方式、轮盘方向、宏序列。
- 编辑态不向远端发送按键；保存后写方案并应用；退出未保存需二次确认。

### 15.9 工具与危险操作

- 观看模式、远程开机、终端、端口映射放在工具页；进入前给出条件与风险提示。
- 重启/关机、删除虚拟屏、结束终端会话、清理传输缓存需要二次确认。
- 端口映射默认关闭；关闭工具页或断开远控会停止全部映射。

### 15.10 账号页

- 入口：主页 `X` / 账号图标。
- 上屏摘要：昵称、登录状态、在线设备、登录方式、签名材料、令牌存储、上次同步。
- 下屏动作：刷新设备、账号与安全、关于、退出登录（危险色 + 二次确认）、返回。
- 退出登录：清除 token 与设备缓存，回到登录页；签名材料/设置保留。
- `Y` 刷新，`X` 退出，`A` 返回，`B` 选择。

## 16. 手柄焦点与单屏模式（2026-11-18 修订）

> 完整键位、屏幕角色、Compose 落地与验收见 [focus.md](focus.md)。

### 16.1 单焦点树

- 双屏页：上屏只读，下屏是唯一操作面；只收集下屏的按钮/列表/页签/开关。
- 单屏页：`.single-app-frame` 是唯一操作面。
- 不提供“上下屏焦点切换”；L1/R1 只切一级页签/分类，L2/R2 切二级页签。
- 上屏 `screen-label` 显示“状态预览 · 不参与焦点”，下屏显示“操作屏 · 焦点在此”。

### 16.2 焦点指示

- 焦点环：深色间隙 + 2dp 高亮环 + 淡柔光；列表内改用内嵌环，避免被 `overflow:hidden` 裁掉。
- 每个可聚焦控件必须有焦点环；静态 `.focus-ring` 只作示意，实际由焦点树驱动。
- 焦点移动时只滚到可见；切页签后重建候选并落到新面板首个可聚焦项。

### 16.3 浮层

- 本地菜单 / IME / 确认层打开时独占焦点树，只收集浮层内控件。
- A/B 先关浮层，再返回页面；关闭后焦点回到打开它的控件。

### 16.4 串流模式

- 默认直通：手柄 → 远端 XInput，本地不显示焦点环；本地菜单用触摸/Back 打开。
- 本地操作：先零值 + `gpd_disconnect`，焦点环出现，L1/R1 切工具箱页签；切回直通时 `gpd_connect`。
- 设计稿为了展示焦点默认“本地操作”，点手柄 chip 可观察直通/本地切换。

### 16.5 文件页改造

- 上屏只保留传输总览（选中什么、传到哪里、还剩多久）。
- 下屏统一为“浏览 / 队列 / 存储”三个页签：选择、下载、上传、暂停、取消、保存路径都在下屏。
- 不再出现“上屏选文件、下屏点下载”的跨屏操作；B 在文件行上打开/选择，X 上传，Y 下载选中。

### 16.6 单屏版

- 每个页面一套：`single-landscape-home/stream`、`single-control-center`、`single-files`、
  `single-display`、`single-tools`、`single-account`、`single-settings`、`single-keymap`、`single-login`。
- 832×468：左侧/上方导航 + 右侧/下方内容；640×480：顶部页签 + 单列，必要时滚动。
- 页面内可切宿主尺寸；L1/R1 只切页签/分类，所有动作在同一屏完成。

### 16.7 页面流

- 文件：主页动作条 / 控制中心 → 更多 / 本地菜单“页面”。
- 多屏：控制中心 → 画面与显示 / 本地菜单“页面 → 多屏”。
- 工具：主页“更多/观看/开机” / 控制中心 → 更多 / 本地菜单“页面 → 工具”。
- 账号：主页头部账号图标 / X / 本地菜单“页面 → 账号”。
- 设置：主页头部设置图标 / 控制中心齿轮 / 本地菜单“设置”。
- 二级页带面包屑，A/Back 回主入口。
