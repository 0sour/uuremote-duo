打开本地菜单时先发零值并 `gpd_disconnect`，释放远端按键；关闭后恢复直通。只有“本地操作”模式才用手柄导航抽屉。
实际产品默认手柄直通电脑；本设计稿为展示焦点默认“本地操作”，点手柄 chip 可切回直通。触摸抽屉不会中断；本地菜单只走系统 Return/Back 或触摸按钮，所以远端 Xbox 映射 不会被本地 UI 的 B/A 语义影响。切到“本地操作”时才暂停远端口柄，切换时释放所有按键。 单屏跑下屏时，整个页面在 Presentation 中，Back/IME 由 Presentation 自己接。 内置拼音不依赖系统 IME；系统输入法按钮是可选路径，副屏兼容性需真机验证。
