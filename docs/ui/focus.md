# 手柄焦点与屏幕所有权

> 2026-11-18 · 适用双屏主页/串流/控制中心/文件/多屏/工具/账号/设置/登录，以及全部单屏版。
> 参考 bili-duo `docs/ui/INPUT_AND_FOCUS.md`：**任意时刻只有一个输入所有者、一棵焦点树。**
> DuoRemote 的改造点：把“播放器控制台”换成“串流工具台”，并把文件、多屏、工具、账号、设置都收进同一套控制面。

## 1. 结论：不做上下屏焦点切换

旧稿把文件页做成“上屏浏览 + 下屏队列”，两边都有按钮。手柄要在两棵树之间跳，
既没有可见的切屏键，也无法判断当前焦点在哪块屏，实际不可用。

我们**不补一个“切屏键”**，而是取消上屏的控件：

- 双屏页：**上屏只读**（视频/设备详情/传输总览/屏幕预览/工具预览），
  **下屏是唯一操作面**，所有按钮、列表、页签、开关都在下屏。
- 单屏页：整个 frame 就是唯一操作面。
- L1/R1 不再承担“上下屏切焦点”，改为**一级页签/分类**；L2/R2 切二级页签。
- 上屏的 `screen-label` 常驻“状态预览 · 不参与焦点”，下屏常驻“操作屏 · 焦点在此”，
  用户一眼能看出按键会作用在哪。

这和 bili-duo 的“播放器激活时下屏焦点树拥有全部按键”是同一条契约；
区别是 bili-duo 的左栏是播放控制，我们的下屏是工具箱 + 设置 + 文件 + 工具。

## 2. 屏幕角色

| 页面 | 上屏 | 下屏（唯一操作面） |
| --- | --- | --- |
| 主页 | 选中设备详情、连接偏好 | 设备列表、连接/文件/观看/开机/更多、账号/刷新/设置 |
| 串流 | 远程桌面（只读；直接触摸是触屏路径，不是手柄焦点） | 工具条、触摸板/键盘/快捷键/状态、本地菜单 |
| 控制中心 | 远程桌面 | 画面与显示/外设/安全/更多、应用并重连 |
| 文件 | 传输总览、进度、本机空间 | 浏览/队列/存储三个页签，下载/上传/暂停/取消 |
| 多屏 | 当前屏幕预览 | 显示器/超级屏/虚拟屏、屏幕切换、创建/删除 |
| 工具 | 观看/开机/终端/端口预览 | 工具页签、开关、危险操作确认 |
| 账号 | 账号摘要 | 刷新、账号安全、关于、退出 |
| 设置 | 配置摘要与主题预览 | 分类 + 选项 |
| 登录 | 二维码/短信说明 | 刷新二维码、短信表单、登录 |

只有两类“上屏可操作”的例外，且都**不进入手柄焦点树**：

1. 串流的直接触摸：单指点按/长按/双指滚动，是触屏路径；手柄仍只在下屏。
2. 按键映射参考稿的上屏预览：只做静态展示，未排期。

## 3. 键位

| 输入 | 行为 |
| --- | --- |
| 方向键 / 左摇杆 | 当前操作面内移动焦点；列表/网格自动滚动到焦点 |
| B / Enter | 确认、打开、切换开关 |
| A / Esc / Back | 关闭 IME/本地菜单/确认层；再返回上一页 |
| L1 / R1 | 一级页签/分类：控制中心分组、设置分类、文件三页签、工具四页签 |
| L2 / R2 | 二级页签：控制中心“画面/显示”“手柄/触摸板与键盘/声音” |
| X / Y | 页面动作：上传/下载、新建/删除、退出/刷新、应用/恢复默认 |
| START | 手柄说明浮层（键位表） |
| 触摸 | 点按即聚焦并执行，和手柄共用同一棵焦点树 |

> 实体丝印：B 确认、A 返回。非直通时用于本地焦点；串流直通时所有手柄键（含 START）
> 都发给远端，只有 SELECT/BACK 保留给本地菜单。打开本地菜单、控制中心或退出直通后，
> START 才打开说明浮层。

## 4. 焦点环

- 外圈 3–5dp 深色间隙 + 2dp 高亮环（暗色主题 `#EAF6FF`，亮色主题 `#0B0D10`），
  外加一圈很淡的青色柔光；不覆盖文字/图标。
- 在 `overflow:hidden` 的列表里改为**内嵌环**（2dp 环 + 3dp 间隙），
  避免第一行/最后一行被容器裁掉。
- 焦点移动时 `scrollIntoView({block:'nearest'})`，只滚到可见，不把整页拉走。
- 任何可聚焦控件都必须有 `.gp-focus` 等价实现；禁止只给静态 `.focus-ring` 假装焦点。
- 参考稿里用 HTML 的 `mockup.js` 键盘/手柄运行时模拟；Compose 用
  `focusRequester` + `focusProperties` + `onKeyEvent`，不要依赖默认焦点顺序。

## 5. 焦点树与浮层

- 双屏：只收集 `.screen-bottom` 内的焦点；`.screen-top` 的 `button/a/tabindex` 必须清空。
- 单屏：只收集 `.single-app-frame` 内的焦点。
- 本地菜单、IME 浮层、确认层：打开时**独占焦点树**，只收集浮层内控件；
  关闭后回到打开它的控件。
- 页签切换后重建候选列表；原焦点隐藏时落到新面板第一个可聚焦控件。
- 长按方向只移动一格；B/A/L1/R1/L2/R2 忽略 repeat，避免连跳。

## 6. 串流的两种手柄模式

| 模式 | 手柄输入 | 本地焦点环 | 说明 |
| --- | --- | --- | --- |
| 直通电脑（默认） | 60Hz `gpd_update` → 远端 XInput | 不显示 | 下屏用触摸操作；`SELECT`/系统返回打开本地菜单，其余手柄键（含 START）都发给远端 |
| 本地操作 | 暂停直通，先零值 + `gpd_disconnect` | 显示 | 方向键/ B / A / L1 / R1 导航下屏；切回时 `gpd_connect` |

设计稿为了展示焦点系统，串流页默认切到“本地操作”；点手柄 chip 可切回直通，
HUD 变黄、焦点环消失。

## 7. 单屏版

每个页面都有独立单屏稿，统一规则：

- 832×468（上屏 Activity）默认左侧/上方导航 + 右侧/下方内容；640×480（下屏 Presentation）
  改为顶部页签 + 单列内容，必要时纵向滚动。
- 单屏只有一棵焦点树，不存在“切屏”；L1/R1 只切页签/分类。
- 上屏/下屏两种宿主共用同一份状态与同一套键位；系统 Back/IME 由当前宿主接。
- 页面清单：`single-landscape-home.html`、`single-landscape-stream.html`、
  `single-control-center.html`、`single-files.html`、`single-display.html`、
  `single-tools.html`、`single-account.html`、`single-settings.html`、
  `single-keymap.html`、`single-login.html`。

## 8. 页面流

| 页面 | 入口 A | 入口 B |
| --- | --- | --- |
| 文件 | 主页下屏动作条“文件” | 控制中心 → 更多 / 本地菜单“页面” |
| 多屏 | 控制中心 → 画面与显示 → 显示器/虚拟屏 | 本地菜单“页面 → 多屏” |
| 工具 | 主页“更多/观看/开机” | 控制中心 → 更多 / 本地菜单“页面 → 工具” |
| 账号 | 主页头部账号图标 / X | 本地菜单“页面 → 账号” |
| 设置 | 主页头部设置图标 | 控制中心齿轮 / 本地菜单“设置” |
| 按键映射 | 控制中心 → 更多 | 本地菜单“页面 → 按键映射”（参考） |

所有二级页底部都有面包屑：`主页 › 文件传输`、`串流 › 控制中心 › 多屏` 等；
A/Back 返回主入口，不返回“死路”。

## 9. Compose 落地要点

- `MainActivity` 持有唯一的 `InputRouter`；串流时按模式决定转发远端还是下屏焦点树。
- 下屏 `Presentation` 的根 `FocusRequester` 作为默认落点；上屏不注册 focusable。
- 列表用 `LazyColumn` + `focusRequester` + `FocusDirection`；切页签时把焦点请求到
  新页签或首个可聚焦项，避免焦点留在隐藏面板。
- 浮层用 `FocusRequester` 捕获焦点并设置 `focusProperties { down/up = Cancel }`，
  关闭时恢复来源控件。
- 焦点环按 tokens 绘制在 `clip` 之前；列表项留 4–7dp 透明余量。
- 手柄直通与本地操作切换必须 release-all + `gpd_disconnect` / `gpd_connect`。
- 单屏宿主复用同一套 Composable，只换根尺寸与导航形态，不复制业务状态。

## 10. 验收

- 每个双屏页：上屏无焦点环、无按钮；下屏首屏有一个可见焦点环。
- L1/R1 只切页签/分类，不改变焦点所在的屏。
- 打开本地菜单/IME 后，方向键只在浮层内移动；A/B 关闭后回到原控件。
- 串流直通模式：手柄不驱动本地焦点；切到本地操作后焦点环出现，切回后消失。
- 单屏 832 与 640 两种尺寸：所有按钮可达，最后一行不被 footer 遮住；
  L1/R1 能切到每个页签/分类。
- 从主页/串流/控制中心都能进入文件、多屏、工具、账号、设置，并能 A 返回。
