# DuoRemote UI 设计 Token

> 版本：v0.1 设计稿（2026-11-11）
> 适用：Retroid Pocket Duo 双屏（上屏 832×468dp / 下屏 640×480dp），以及单屏横屏（上屏 Activity 或下屏 Presentation）。竖屏不在设计范围内。
> 对应实现：`docs/ui/mockup.css` 中的 CSS 变量；Android 端在 `ui/theme/` 中映射为 Compose token。
> 说明：所有尺寸单位默认是 **dp**；HTML 设计稿按 1 CSS px = 1dp 绘制，可用右上角缩放切换查看。
> 行为、状态、焦点、异常与验收见 [spec.md](spec.md)；本文只保留视觉 token 与交互摘要。

---

## 1. 设计原则

1. **上屏看，下屏操作。** 上屏尽量干净：设备详情或远程桌面，不放常驻按钮；所有操作集中在下屏工具箱。
2. **焦点优先。** 手柄用户不依赖触摸也能完成：设备选择、连接、断开、切工具箱 Tab。焦点环必须始终可见。
3. **信息分层。** 下屏 640×480dp 很矮：一屏只做一件事；用 Tab/分页而不是纵向堆叠。
4. **暗色为主。** 远程桌面和视频场景多，暗色减少干扰；亮色主题作为可选。
5. **触摸与手柄并存。** 工具箱按钮 ≥ 44dp；手柄事件在入口归一化；触摸下屏不打断远端手柄。
6. **状态明确。** 在线/离线、连接阶段、输入法状态、手柄直通状态都要有文字 + 颜色 + 图标，不只靠颜色。
7. **串流时手柄默认直通电脑。** 本地菜单用系统返回/Return 打开，不占用任何手柄键；只有主动切到“本地操作”时才暂停远端口柄，切换时释放所有按键，避免远端卡键。
8. **单屏也是横屏。** 单屏模式可以在上屏（Activity 832×468dp）或下屏（Presentation 640×480dp）运行；两种宿主都必须支持手柄和 IME。

### 2.3 语义色使用规则

- 在线：`--online` 圆点 + “在线”文字；离线：`--text-tertiary` 圆点 + “离线”。
- 连接中：`--warning` 脉冲圆点 + “正在连接”；失败：`--error` + 原因。
- 选中/焦点：`--accent` 边框或 `--focus-ring` 外环；不要同时用两种强色。
- 禁用：降低不透明度到 38%，不要只改文字颜色。

## 3. 字体

字体族：`Noto Sans SC` / `Roboto` / 系统无衬线；数字与统计用 `Roboto Mono` / `JetBrains Mono`。

| Token | 字号/行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| `display` | 28 / 34 | 600 | 上屏设备名、空态大标题 |
| `headline` | 22 / 28 | 600 | 页面标题、登录标题 |
| `title` | 18 / 24 | 500 | 卡片标题、设置分组 |
| `body` | 14 / 20 | 400 | 正文、设备信息 |
| `body-strong` | 14 / 20 | 600 | 强调、按钮文字 |
| `label` | 12 / 16 | 500 | 标签、Chip、按键提示 |
| `caption` | 11 / 14 | 400 | 辅助说明、时间 |
| `mono` | 12 / 16 | 500 | 延迟、FPS、码率、分辨率 |

规则：
- 下屏正文不小于 13sp；上屏详情正文 14–16sp；单屏横屏正文 13–15sp。
- 大标题最多 2 行；设备名过长用省略号，详情页可完整显示。
- 数字统计使用等宽字体，避免跳动。
- 支持系统字体缩放 1.0–1.3；超过 1.3 时布局改用滚动。

| Token | 值 |
| --- | --- |
| `space-1` | 4dp |
| `space-2` | 8dp |
| `space-3` | 12dp |
| `space-4` | 16dp |
| `space-5` | 20dp |
| `space-6` | 24dp |
| `space-8` | 32dp |
| `space-10` | 40dp |
| `space-12` | 48dp |

- 下屏外边距 16dp；卡片内边距 14–16dp；卡片间距 10–12dp。
- 上屏外边距 24dp；详情卡片内边距 24dp。
- 触摸目标最小 44×44dp；键盘按键高度 38–42dp，间距 6dp。

### 4.2 圆角

| Token | 值 | 用途 |
| --- | --- | --- |
| `radius-xs` | 6dp | 小标签、键帽 |
| `radius-sm` | 8dp | 键盘键帽、Chip |
| `radius-md` | 12dp | 按钮、输入框 |
| `radius-lg` | 16dp | 卡片、面板 |
| `radius-xl` | 20dp | 大卡片、浮层 |
| `radius-pill` | 999dp | 胶囊按钮、状态 Chip |

### 4.3 阴影/层级

- 卡片：`0 1px 0 rgba(255,255,255,.03) inset` + 1dp `--outline`，不使用大阴影。
- 浮层/对话框：`0 16px 48px var(--shadow)` + 1dp `--outline`。
- 焦点环优先于阴影；不要用阴影表达焦点。

## 5. 布局

### 5.1 上屏（832×468dp）

```text
┌──────────────────────────────────────────────┐
│ 24dp 边距                                     │
│  顶部 40dp：品牌/状态/时间（可选）              │
│  主区：左 60% 设备信息 / 右 40% 操作与提示       │
│  底部 32dp：B 连接 · A 返回 等提示               │
└──────────────────────────────────────────────┘
```

- 详情页：设备名 `display`；状态 Chip；信息行（系统/分辨率/上次连接/网络）；右侧大按钮/提示卡。
- 串流页：视频铺满，黑底，`SCALE_ASPECT_FIT`；默认无 OSD；可选左上角 12dp 小统计 Chip。
- 连接页：居中进度条 + 阶段文案；不要放大量日志。

### 5.2 下屏（640×480dp）

```text
┌──────────────────────────────────────────────┐
│ 16dp 边距                                     │
│  顶栏 44dp：标题/账号/刷新/设置                 │
│  Tab 36dp：触摸板 | 键盘 | 快捷键 | 状态        │
│  内容区：约 360dp 高                           │
│  底部提示 28dp：实体键位/手势提示               │
└──────────────────────────────────────────────┘
```

- 设备列表：每屏 4 张卡（卡高 76dp，间距 10dp），可滚动；焦点卡带 2dp 外环 + 左侧 3dp 强调条。
- 工具箱：内容区高度约 360dp；触摸板/键盘/快捷键/状态各自占满。
- 键盘：6 行，行高 40dp + 6dp 间距；顶栏输入行 36dp；修饰键行 36dp。
- IME 浮层：覆盖内容区，顶部拼音组合框 + 内置候选条 + 键盘；右上角“系统输入法”按钮。

### 5.3 单屏横屏（Duo 上屏 / 下屏）

单屏模式必须横屏。两种宿主：

| 宿主 | 尺寸 | 说明 |
| --- | --- | --- |
| 上屏 Activity | 832×468dp | 普通 Activity；系统 Back/IME 正常 |
| 下屏 Presentation | 640×480dp | 整个 UI 在 Presentation；Back/IME 自己接 |

**主页（master-detail）**

- 顶栏 48dp；左列表 55–58%，右详情 42–45%；底部提示 28dp。
- 832×468：左约 460dp / 右约 348dp；卡片 72dp，显示 4–5 张。
- 640×480：左约 356dp / 右约 268dp；卡片 64dp，显示 4 张；字号降 1sp。
- 640 宽度下右侧详情只保留：设备名、状态、系统、连接按钮/提示；次要信息省略。
- 空态/登录：列表区居中，右侧详情换成说明卡。
- 焦点环同样外扩 4dp；640 宽度下列表左右至少留 8dp 余量。

**串流**

- 视频铺满，黑底 letterbox；底部工具箱抽屉默认 42% 高；切到键盘页/展开 IME 自动升到 58%，可拖到 68%；收起后只剩视频 + 悬浮“工具箱”按钮。
- 抽屉顶部：拖拽把手 + 设备/状态 + 手柄模式 Chip + 断开。
- 抽屉 Tab：触摸板/键盘/快捷键/状态；640×480 下内容区约 200dp，触摸板可缩小或滚动。
- 系统返回/Return：先收系统 IME/内置浮层，否则打开本地菜单；抽屉不消费返回。
- 手柄：默认直通；本地菜单可切“本地操作”来导航抽屉。切换时释放远端所有按键并断开会话手柄，切回时重连。
- IME：默认用内置拼音浮层（本地词典、候选条），不依赖系统输入法；键盘/浮层保留“系统输入法”按钮唤起 Gboard/搜狗。下屏 Presentation 用自建 ImeState；上屏 Activity 也不能只信 `WindowInsets.isImeVisible`。

## 6. 组件规格

### 6.1 设备卡

| 属性 | 值 |
| --- | --- |
| 高度 | 76dp（下屏）/ 84dp（单屏） |
| 背景 | `--surface-1` |
| 边框 | 1dp `--outline` |
| 圆角 | `--radius-lg` |
| 内边距 | 14dp 水平，12dp 垂直 |
| 图标 | 36dp 容器 + 20dp 线性图标 |
| 标题 | `title`，1 行省略 |
| 副标题 | `caption`，在线状态 + 上次连接 |
| 焦点 | 外环 2dp `--focus-ring`，外扩 4dp；左侧 3dp `--accent` 条 |
| 选中 | 背景 `--accent-soft`，边框 `--accent` |
| 离线 | 整体 55% 不透明度，状态点灰色 |

### 6.2 主按钮/次按钮

- 主按钮：高 44dp，圆角 `--radius-md`，背景 `--accent`，文字 `--on-accent`，`body-strong`；按下 `--accent-strong`。
- 次按钮：高 44dp，透明背景，1dp `--outline-strong`，文字 `--text-primary`。
- 危险按钮：文字/边框 `--error`；仅断开/退出使用。
- 图标按钮：44×44dp，20dp 图标，圆角 `--radius-md`；焦点环同上。

### 6.3 Tab / Chip

- Tab 高 36dp，圆角 `--radius-sm`；未选中 `--text-secondary`；选中 `--accent-soft` 背景 + `--accent` 文字 + 底部 2dp 指示条。
- 状态 Chip：高 24dp，`--radius-pill`，12sp；在线用 `--online` 文字 + 10% 背景；离线用 `--text-tertiary`。

### 6.4 触摸板

- 区域：`--surface-inset`，圆角 `--radius-lg`，1dp `--outline`；内嵌 1dp 点阵（`radial-gradient`，点距 18dp，透明度 6%）。
- 默认手势提示：底部居中 `caption`：“单指移动 · 点击左键 · 双指滚动 · 双指点击右键”。
- 点击按钮行：左键/中键/右键 3 个 44dp 高按钮；拖拽锁定用 Toggle Chip。
- 按下时：边框 `--accent`，背景轻微提亮；点击有 40ms 高亮。
- 灵敏度：设置页滑杆，默认 1.0×，范围 0.4–2.5×。

### 6.5 键盘

- 键帽：`--surface-3`，1dp `--outline`，圆角 `--radius-sm`，高 40dp；文字 `body-strong` 13sp。
- 按下：背景 `--accent-soft`，边框 `--accent`，文字 `--accent`。
- 修饰键锁定：背景 `--accent-soft`，顶部 2dp 指示条；再按一次取消。
- 特殊键（Ctrl/Alt/Shift/Win/Enter/Backspace）：略深背景 `--surface-2`，文字 `--text-secondary`。
- 长按连发：Backspace/方向键 350ms 后每 50ms 一次；视觉上按键保持按下态。
- 中文输入行：高 36dp，左侧输入图标 + 当前模式文案，右侧展开图标；点击输入行打开内置拼音浮层。旁边只保留“系统”按钮；键盘底部增加“中/英”键，直接切换内置拼音/英文，不再单独放“拼音”按钮。
- 中文候选条：高 30dp，`--surface-2`，左侧拼音组合（`mono` + 青色下划线），中间 5–7 个候选，右侧“内置拼音”标识；空格提交首选，数字键 1–9 选择。单屏 640 宽度下候选收进输入行，不额外占一行。
- 内置键盘与系统输入法互斥：系统 IME 唤起时隐藏内置键盘，避免双键盘叠加。

### 6.6 IME 浮层（内置拼音 / 系统输入法）

- 覆盖下屏内容区或单屏全屏；背景 `--bg` 95% + 8dp 模糊（实现可用纯色）。
- 顶部：拼音组合框（`--surface-2`，1dp `--outline`，圆角 `--radius-md`，高 44dp）+ “系统输入法”按钮 + “完成”按钮。
- 中间（默认内置）：本地拼音候选条 + 内置 QWERTY；候选由本地词典生成，不由 Android IME 绘制。
- 系统输入法状态：显示“系统输入法已唤起”提示，候选和键盘由 Gboard/搜狗绘制；提供“返回内置键盘”。
- 底部：提示“中文候选经 text_input 发送；英文/控制键走 kbd_press”。
- A/返回：系统 IME 可见时先收系统 IME；否则先收内置浮层；不要直接退出串流。

### 6.7 状态/统计

- 4 个指标卡 2×2：FPS、码率、延迟、丢包；每卡 76dp 高，`--surface-1`。
- 详情行：分辨率、编码、解码器、P2P/TURN；用 `mono`。
- 弱网：延迟 > 80ms 或丢包 > 2% 时数字变 `--warning`；> 150ms 或 > 5% 变 `--error`。
- 顶部状态条：设备名 + 在线点 + 延迟 Chip + 静音/设置/断开按钮。

### 6.8 提示/弹窗

- Snackbar：底部 16dp，`--surface-2`，圆角 `--radius-md`，2.5s 自动消失。
- 确认弹窗：标题 `title`，正文 `body`，两个 44dp 按钮；危险操作按钮在右。
- 错误页：图标 40dp + 标题 + 原因 + “重试/返回”；不要显示原始堆栈。

### 6.9 焦点环

- 外环 2dp `--focus-ring`，与控件间隔 2dp（用 `outline-offset` 或双层 border）。
- 焦点卡：外扩 4dp，避免被父容器裁切；Lazy 列表首行留 4dp padding。
- 动画：进入 120ms 淡入；失焦立即消失（不留残影）。
- 点击/触摸也先给目标焦点，再执行动作。

## 7. 交互与按键

> 完整状态机、焦点模型、异常流程与验收见 `spec.md` §6–§9；本节是速查摘要。

### 7.0 实体键语义（Duo）

Duo 的实体位置固定：下 B、右 A、左 Y、上 X。系统“手柄风格”只改固件输出的 keycode，
不改实体丝印。**UI 提示始终按实体丝印写**；输入入口统一归一化为 canonical Xbox，
业务层只认 canonical Xbox。

| 实体位置 | 丝印 | 本地 UI 语义（canonical） | 远端 Xbox 语义 |
| --- | --- | --- | --- |
| 下方 | B | 确认 / 连接 / 选择（canonical A） | Xbox A（4096） |
| 右方 | A | 返回 / 关闭（canonical B） | Xbox B（8192） |
| 左方 | Y | 刷新 / 上下文（canonical X） | Xbox X（16384） |
| 上方 | X | 账号 / 更多（canonical Y） | Xbox Y（32768） |
| D-pad | — | 焦点移动 | D-pad 1/2/4/8 |
| START | — | 设置 / 菜单 | Start（16） |
| RETURN | — | 本地菜单 / 返回 | **不发送** |

关键：**本地 UI 的 B 确认/A 返回，和远端 Xbox 的 A/B 不是同一套字母**。输入入口做
`GamepadStyle.normalizeFaceKey`（Retro 时 A↔B、X↔Y），之后本地用 canonical A=确认、
B=返回；远端直通则发送 canonical A/B/X/Y 的 XInput 位掩码。这样远端游戏看到的是
标准 Xbox 映射，不会被本地 UI 的确认/返回语义污染。

### 7.1 双屏主页

| 输入 | 行为 |
| --- | --- |
| D-pad / 左摇杆 | 移动设备焦点 |
| B（实体下方） | 连接选中设备 |
| A（实体右侧） | 返回 / 退出确认 |
| Y（实体左侧） | 刷新设备列表 |
| X（实体上方） | 账号 / 登录 |
| START | 设置 |
| L1/R1 | 切换一级页面（设备/最近/设置，可选） |

> 提示按实体丝印：`B 连接 · A 返回 · Y 刷新 · X 账号 · START 设置`。
> 长按方向/返回/肩键吞 repeat，避免连跳；同一 keycode 40ms 去重。

### 7.2 双屏串流

| 输入 | 行为 |
| --- | --- |
| 手柄 | **默认直通远端 Xbox**（A/B/X/Y、D-pad、LB/RB、LT/RT、L3/R3、Start/Back），60Hz 节流 |
| 下屏触摸 | 工具箱；不打断手柄直通 |
| 系统 Back / Return | 打开本地菜单；暂停直通并释放手柄，菜单内可用手柄导航；关闭后恢复 |
| 下屏“菜单”按钮 | 与系统 Back 相同（触摸入口，不占手柄键） |
| 上屏触摸 | 可选“直接触摸”模式；默认关闭，避免误触 |
| 手柄模式 Chip | `直通电脑` / `本地操作`；本地操作时暂停远端口柄，切回时重连 |

> **不要用 L1+R1+START 之类的组合键开本地菜单**：组合键会短暂改变远端手柄状态。
> 本地菜单只走系统 Return/Back 或下屏触摸按钮，保证远端映射不被占用。

### 7.3 键盘/IME

两条输入路径，默认内置，系统输入法随时可唤起：

1. **内置拼音（默认）**
   - 键盘自带本地拼音引擎和词典，输入字母后实时显示候选；不依赖系统输入法，下屏 Presentation 也能用。
   - 键盘底部有独立的“中/英”键，直接切换中文/英文；不再单独放“拼音”按钮，点击输入行展开完整候选浮层。
   - 空格提交首选，数字键 1–9 选候选，`中/英` 切换；英文/控制键仍走 `kbd_press`/`kbd_release`。
   - 中文提交走 `text_input`，一次发送整段候选，不逐字发 VK；失败时回退 `SendToRom{RomMsg_Text}`。
   - 组合中的拼音只在本机显示，不发送到电脑；退格先删拼音，再删已提交文本。
2. **系统输入法（按钮）**
   - 点“系统输入法” → 聚焦隐藏/可见输入框 → `InputMethodManager.showSoftInput`，Gboard/搜狗出现在当前屏幕。
   - 系统 IME 唤起时隐藏内置键盘，避免双键盘；系统 `commitText` 同样转发为 `text_input`，`setComposingText` 只本地显示。
   - 系统 IME 收起后回到内置拼音；下屏 Presentation 必须真机验证系统 IME 是否愿意在副屏显示，失败则提示并留在内置拼音。

- Enter/Backspace：有组合时 Backspace 先删拼音、Enter 先提交组合，不额外发 VK；无组合时发 VK 13/8。
- 本地操作模式下：D-pad 左右移动候选，B 上屏首选，A 收起浮层；直通模式下键盘只用触摸，不拦截手柄。
- **A/返回** → 系统 IME 可见时先收系统 IME；否则先收内置浮层；再按才关键盘面板/回工具箱。
- **B/确认** → 在本地操作模式下确认/发送；直通模式下 B 属于远端，不拦截。
- 断开/切页 → release all 按住的键，清空拼音组合与候选。

### 7.4 单屏横屏

单屏模式可以在 **上屏 Activity** 或 **下屏 Presentation** 运行，二者都是横屏：

| 宿主 | 主页 | 串流 | 手柄 | 系统 Back | IME |
| --- | --- | --- | --- | --- | --- |
| 上屏 Activity（832×468dp） | master-detail | 视频 + 抽屉 | Activity Router | Activity | 内置拼音 + 系统 IME |
| 下屏 Presentation（640×480dp） | master-detail | 视频 + 抽屉 | Presentation Router | Presentation 自己接 | 内置拼音 + 系统 IME（副屏需真机验证） |

- 主页：左列表 + 右详情；B 连接、A 返回、Y 刷新、X 账号、START 设置。
- 串流：视频铺满，底部工具箱抽屉默认 42%；键盘页/IME 自动升到 58%，可拖到 68%；收起后只剩视频 + 悬浮“工具箱”按钮。
- 串流时手柄默认直通；系统 Back/Return 打开本地菜单；抽屉按钮触摸操作；
  需要用手柄操作抽屉时，在本地菜单切“手柄：本地操作”，切换时释放远端按键并断开 `gpd`。
- 下屏 Presentation：不要用 `Dialog`/`AlertDialog`，所有模态做 Compose overlay；
  系统 Back 用 `dispatchKeyEvent` + `OnBackInvokedCallback` 双接并 250ms 去抖；
  IME 不要只信 `WindowInsets.isImeVisible`，自己维护 `ImeState.shown`。
- 下屏单屏时上屏 Activity 可以是纯黑/待机；所有焦点和按键都在 Presentation。
- 单屏跑下屏时，Activity 的 `dispatchKeyEvent` 可能收不到按键，必须由 Presentation 的
  `GamepadRouter` 处理；不要假设“按键一定先到 Activity”。

### 7.5 手柄归属与远端映射

三态：

| 状态 | 页面 | 手柄 | 远端输入 |
| --- | --- | --- | --- |
| `HOME_LOCAL` | 设备列表/详情/登录/设置 | 本地导航 | 无 |
| `STREAM_PASSTHROUGH` | 串流，默认 | 直通 Xbox | 正常 `gpd_update` |
| `STREAM_LOCAL` | 本地菜单/工具箱“本地操作” | 本地导航 | **暂停**：发零值 + `gpd_disconnect`；切回重连 |

规则：

1. **进入串流**：首次 `gpd_update` 前发 `gpd_connect`；按钮/轴变化 60Hz 节流发送。
2. **离开串流/断开**：发零值 `gpd_update` + `gpd_disconnect`，并释放所有按住的键盘/鼠标键。
3. **切到本地操作**：先发零值 + `gpd_disconnect`，再让本地焦点树接手柄；切回直通时重新 `gpd_connect`。
4. **不要全局拦截 `dispatchGenericMotionEvent`**：只在本地模式且确有摇杆消费者时消费
   `AXIS_X/AXIS_Y`；`AXIS_HAT_X/AXIS_HAT_Y`（D-pad）必须放行。
5. **手柄/键盘/鼠标可以同时存在**：下屏触摸板发鼠标事件，不抢手柄；手柄直通时仍可触摸工具箱。
6. **本地导航吞 repeat**：方向、返回、肩键的 `repeatCount>0` 本地吞掉；远端直通按 60Hz 状态发送，
   不受本地 repeat 逻辑影响。
7. **UI 提示按实体丝印**：B 连接/A 返回；不要写“canonical A”给用户看。

## 9. 实现映射（Compose）

- 颜色：`DuoColors` data class + `CompositionLocal`；不要直接散落 `Color(0x...)`。
- 字体：`MaterialTheme.typography` 自定义 `display/headline/title/body/label/caption/mono`。
- 间距：`DuoSpacing`（4/8/12/16/20/24/32/40/48）。
- 圆角：`DuoRadius`（6/8/12/16/20/999）。
- 焦点：统一 `duoFocusRing()` modifier；外扩 4dp，先绘制环再 clip。
- 下屏：`SecondScreenPresentation` + ComposeView；`640×480dp` 断点单独布局，不复用常规平板断点。
- 上屏：`TopHost` 状态机；视频用 `SurfaceViewRenderer`，详情用 Compose。
- 单屏：`SingleHost` 可在 Activity 或 Presentation 内复用；主页用 master-detail（左列表/右详情），
  串流用视频 + 底部抽屉。不要用 `ModalBottomSheet` 的 Dialog 实现——下屏 Presentation 里会
  window type mismatch；改成 Compose 布局内 overlay/`AnimatedVisibility`。
- 输入：`GamepadRouter` 持有 `HOME_LOCAL / STREAM_PASSTHROUGH / STREAM_LOCAL` 三态；
  Activity 和 Presentation 共用同一个 router（按当前宿主注册），串流直通时只发 `gpd_update`，
  本地模式才把按键送进 Compose 焦点树。
- 输入法：`BuiltinPinyinEngine` 负责拼音切分/词典候选；`ImeMode` 为 `BUILTIN / SYSTEM`。
  中文提交统一走 `Session.sendText()` → `text_input`；系统 IME 用隐藏 `BasicTextField` +
  `InputMethodManager`，composing 文本只本地显示，commit 后才发送。
- 返回：Activity 和 Presentation 各自接 BACK/ESC；下屏还要注册 `OnBackInvokedCallback`；
  统一走 `Session.handleBackKey()`，优先级 IME → overlay → 页面返回。
- IME：两种宿主都优先内置拼音，系统输入法作为可选路径；下屏用 `DuoImeState` 自己记账，
  上屏也不要只信 `WindowInsets.isImeVisible`，Presentation 里不要用 Dialog 实现输入法面板。

## 12. 手柄焦点 / 单屏 shell（2026-11-18）

### 12.1 焦点环

- 标准：`outline 2dp` + `outline-offset 3dp` + `box-shadow 0 0 0 5dp gap` + 22dp 柔光（透明度 ≤30%）。
- 小控件（按键/分段/图标按钮/开关）：`offset 2dp` + `4dp gap` + 14dp 柔光。
- 列表内（`overflow:hidden`）：`outline:none`，改用 `inset 0 0 0 2dp ring` + `inset 0 0 0 5dp gap`。
- 亮色主题：环色 `#0B0D10`、间隙 `#F7F8FA`；暗色主题反过来。
- 焦点环不得覆盖文字/图标；列表项至少留 4dp 透明余量。

### 12.2 屏幕状态

- 屏标签：11sp tertiary；状态 pill 高 16dp、9sp，圆点 5dp。
- 操作屏：`online` 色 + 10% 底 + 34% 边，文案“操作屏 · 焦点在此”。
- 预览屏：透明底 + 24% 边，文案“状态预览 · 不参与焦点”。
- 串流直通：`warning` 色 + 8% 底，文案“手柄直通 · 本地焦点未激活”。

### 12.3 HUD（设计稿辅助）

- 固定底部居中，高 30dp，圆角 pill，`surface` 底 + 1dp 边；10sp。
- 内容：模式 + 方向/B/A/L1R1/L2R2/XY/START + 当前焦点；窄屏自动换行。
- HUD 只用于评审，不进入 Compose 产品界面；产品内用页脚键位提示 + 焦点环。

### 12.4 单屏 shell

- Frame：832×468 或 640×480，圆角 18，外圈 6dp 深色。
- Bar：48dp（640 下 44dp），左侧返回 32dp + 标题 15/9 + 状态 chip + 右侧动作。
- Tabs：26dp 高、7dp 圆角；active 用 `accent-soft` + 24% 边。
- Body：832 左右分栏（侧栏 154dp）；640 单列，内容可纵向滚动。
- Foot：28dp，9sp；`kbd` 16dp 高、8sp 等宽。
- 面板：`.sa-panel` 在 640 下只显示 `.is-active`；832 下可并排。

### 12.5 文件单一操作台

- 上屏：传输总览卡（选中项、方向、速度、剩余、任务数），无按钮。
- 下屏：页签“浏览/队列/存储”；浏览 = 路径 + 快捷位置 + 6 行列表 + 动作条。
- 文件行 31dp，列 `20 / 1fr / 64 / 74`；选中 `accent-soft`。
- 队列项 8dp 内边距；进度 4dp；操作按钮 24dp。
- 存储行 26dp；路径用 mono 9sp。

### 12.6 页面流

- 二级页面包屑：9sp tertiary，当前项 `text-secondary` + 600。
- 入口按钮：24dp 高、7dp 圆角；主入口用 `accent-soft`。
- 跨页动作统一放在操作屏底部动作条或局部菜单，不放到只读屏。
