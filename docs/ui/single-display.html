单屏单焦点 · 超级屏与虚拟屏互斥
单屏多屏页把“显示器 / 超级屏 / 虚拟屏”做成同一屏的页签，列表与参数在 832 宽时并排、640 宽时上下排列。 双屏版的上屏只做当前屏幕预览，屏幕切换全部在下屏；单屏版则全部收进唯一的操作区。双屏版见 duo-display.html。
