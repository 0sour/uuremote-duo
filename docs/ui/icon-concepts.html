怎么选

先定“第一眼”的语义

A · 双屏手柄
最稳，且与 Bili-Duo 同一套扁平双屏语言；缩到 48px 仍像“上下两块屏 + 手柄”。推荐主方案。
B · 斜切双屏
最现代，单色最好做；但“双屏”需要一点解释。适合做主题图标或商店图备选。
C · 门户连线
最强调连接；斜屏在小尺寸略糊，更适合启动页插画，而不是主图标。
D · 掌机正面
最像掌机，但细节多；48px 容易读成“游戏机”，远控语义最弱。
E · 光标屏幕
最像远控，双屏感最弱；更像功能图标，适合控制中心或通知栏。

建议：A 做主图标，B 做单色/主题图标备选；C 留给启动页大图。这样“双屏 + 远控”在小尺寸和品牌场景都不丢。
