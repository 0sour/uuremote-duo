RP DUO · DUAL SCREEN

上屏看，下屏操作。
一个焦点树，手柄走到底。

双屏主页：上屏只做设备详情/桌面/状态，所有按钮、列表和页签都在下屏一棵焦点树里；不需要按任何键在上下屏之间切焦点。 串流内还有“控制中心”，直接改分辨率/帧率/画质/码率；每个页面都有独立的单屏版（832×468 / 640×480）。

832×468dp 上屏 640×480dp 下屏 串流内控制中心 文件传输 多屏 / 超级屏 XInput 手柄直通 手柄焦点规范

页面

点击卡片打开可交互 HTML；右下角/顶部可切亮色与缩放

双屏主页

下屏设备列表 + 连接/文件/观看/开机动作条；上屏只显示选中设备详情，不参与焦点。

双屏串流 + 工具箱

上屏只读远程桌面；下屏触摸板/键盘/快捷键/状态。手柄默认直通；切到本地操作才出现焦点环。

串流内控制中心 ★

画面与显示 / 外设 / 安全 / 更多；L1/R1 切分类，方向键选择，←→ 改值；待应用与“应用并重连”。

文件传输

上屏只显示传输总览；下屏“浏览/队列/存储”三个页签承担全部操作，不再上下屏各放一套控件。

多屏 / 超级屏 / 虚拟屏

上屏只做当前屏幕预览；屏幕切换、超级屏 4K/144、虚拟屏创建/删除全部在下屏。

按键映射（参考稿 · 未排期）

官方形态参考；Duo 决策不做触屏虚拟按键/轮盘，后续只考虑实体手柄→键鼠模板。

工具：观看模式 / 开机 / 终端 / 端口

上屏只读预览；观看模式、WOL 远程开机、PowerShell 终端、端口映射都在下屏操作。

扫码登录

上屏二维码、下屏说明与短信入口；二维码有效期与刷新。

短信验证码登录

区号/手机号/验证码/重发倒计时，一屏完成。

设置

画面 / 屏幕 / 外设 / 安全 / 网络 / 外观 / 关于；上屏只做配置预览，下屏分类+选项。

账号

上屏只做账号摘要；刷新、账号安全、关于、退出都在下屏行列表里完成。

单屏横屏主页 · 上屏/下屏

同一个 master-detail 布局适配 832×468 上屏 Activity 和 640×480 下屏 Presentation。

单屏横屏串流 · 视频 + 抽屉

视频铺满，工具箱抽屉默认 42%；手柄默认直通，系统返回开本地菜单；键盘内置拼音 + 中/英切换 + 系统输入法。

布局原则

  • 上屏 24dp 边距，主区左 60% 信息 / 右 40% 操作；串流时视频铺满。
  • 下屏 16dp 边距：顶栏 44 / Tab 36 / 内容 ~360 / 底部提示 28。
  • 设备卡 76dp，下屏一屏 4 张；卡片间距 10dp。
  • 触摸目标 ≥44dp；键盘键高 38–42dp，间距 6dp。
  • 焦点环外扩 4dp，先绘制环再 clip；Lazy 首行留焦点余量。
  • 亮色只用于列表/详情/设置；视频始终黑底。
  • 单屏也是横屏：上屏 Activity 832×468 / 下屏 Presentation 640×480，同一套 master-detail + 抽屉。
  • 主页 B 连接/A 返回；串流时手柄默认直通电脑，本地菜单只走系统 Return/Back，不占用任何手柄键。
  • 切“本地操作”才暂停远端口柄，先释放按键再断开会话手柄，切回时重连。
文件：docs/ui/tokens.md（Token/组件/交互全文）、mockup.css（变量与组件样式）、 mockup.js（亮色/缩放/Tab/内置拼音与系统 IME 预览）、sprite.js（内联图标）。 所有页面无外部依赖，双击 HTML 即可在 Edge/Chrome 打开。
