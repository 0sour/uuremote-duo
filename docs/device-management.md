# 设备管理

> 入口：主页右上「⋮」或 SELECT。
> 状态：重命名/重启/移除的 API 与确认流程已完成；尚未对真实账号执行变更。

## 页面

- 上屏只读：当前设备、在线状态、操作说明。
- 下屏/单屏：设备列表 + 「重命名 / 重启 / 移除 / 返回」。
- 手柄：↑↓ 选择，X 重命名，Y 重启，SELECT 移除，A 返回。
- 触摸：点行选择，点底部按钮执行；弹层内点「取消/确认」。
- 重命名会打开系统 IME；确认按钮位于键盘上方。取消不会发送请求。

## API

| 操作 | 方法 / 路径 | Body | 前置条件 |
| --- | --- | --- | --- |
| 重命名 | `PUT /api/v1/device/{id}` | `{"alias":"新名称"}` | 1–40 字，无控制字符 |
| 重启 | `POST /api/v1/device/{id}/reboot` | 空 | 设备在线 |
| 移除（自有） | `POST /api/v1/device/{id}/unbind` | 空 | 设备离线 |
| 移除（共享） | `POST /api/v1/device/share/{id}/unbind` | 空 | 设备离线 |

设备 ID 只接受 ASCII 字母数字、`_`、`-`，最长 128 字符，避免路径注入。
共享设备来自设备列表的 `others_shared_devices`，UI 标记「共享」。

## 安全

- 所有变更都先弹确认层；重命名只有点「确认」才发送。
- 在线设备不能移除；离线设备不能重启；与云端校验一致。
- 操作请求用现有登录 token 与签名头发送；日志不记录 token、设备 ID 之外的账号数据。
- 排序支持在线优先、按名称、最近连接；最近连接记录 8 台，保存在 DataStore。
- 设备搜索尚未做。
